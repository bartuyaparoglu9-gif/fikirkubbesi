FİKİR KUBBESİ WEB SİTESİ

1) Bu klasörü bilgisayarına çıkar.
2) VS Code'da File > Open Folder ile klasörü aç.
3) index.html dosyasına sağ tıkla.
4) Open with Live Server seçeneğine bas.

DÜZENLEME
- Ana içerikler: index.html
- Renkler ve tasarım: style.css
- Menü ve animasyonlar: script.js
- Logo: assets/images/logo.png
- Ana arka plan: assets/images/hero-bg.png

YAYINLAMA
Netlify:
- netlify.com adresine gir.
- Ücretsiz hesap aç.
- Add new site > Deploy manually.
- Bu klasörü sürükleyip bırak.

GitHub Pages:
- GitHub'da yeni public repository oluştur.
- Bu klasördeki dosyaları yükle.
- Settings > Pages > Deploy from a branch > main / root > Save.

NOT
İletişim formu mevcut haliyle cihazdaki e-posta uygulamasını açar.
Gerçek çevrimiçi form için daha sonra Formspree veya Netlify Forms eklenebilir.
